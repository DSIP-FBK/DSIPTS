Inference configuration for Timestral checkpoints.

Only the fields that change the forward pass at inference are kept. The package implements one family of Timestral models: causal modeling trained with Decoupled Horizon Forecasting (DHF), with monotone quantiles, decoded in the advancing refine frame.

dsipts.models.timestral.covariate_encoding module¶

Target encoding of categorical covariates.

Timestral was trained on numeric, target-scaled covariates, so a categorical covariate is turned into numbers before it reaches the model. The default is a per-series smoothed mean-target encoding: in series i, category c becomes

(smooth * mean_i + sum_{i,c}) / (smooth + count_{i,c})

over the series’ context, with smooth = 1. Missing values (NaN) form their own category. A category that never occurs in the context (for example a new value in the horizon of a known covariate) resolves to the series mean.

dsipts.models.timestral.covariate_encoding.target_encode(target_context: ndarray, past_codes: ndarray, future_codes: ndarray | None = None, smooth: float = 1.0) → tuple[ndarray, ndarray | None]¶

Per-series smoothed mean-target encoding.

Parameters:

  • target_context – (T,) target values. Non-finite entries are left out of the means.

  • past_codes – (T,) category codes aligned with target_context; NaN marks a missing value, which is encoded as a category of its own.

  • future_codes – Optional (H,) codes over the horizon (known covariates).

  • smooth – Weight of the series mean in each category mean.

Returns:

(encoded_past, encoded_future) float32 arrays; encoded_future is None when future_codes is None.

dsipts.models.timestral.forecaster module¶

Probabilistic forecasting with Timestral, including the clampsym test-time augmentation.

TimestralForecaster.forecast takes a context (B, V, T) (series, variates, time; NaN marks a missing value) and returns quantile forecasts (B, V, H, Q). Horizons longer than one decode block are forecast block by block, feeding each block’s median back as context.

Clampsym (both options on by default):

  • Symmetric averaging forecasts the context and its negation, reflects the second forecast back (-Q(1 - p)), and averages the two. Every covariate row is negated with the context: numeric covariates, 0/1 indicators, target encodings and raw codes.

  • Non-negative clipping clamps the forecast at 0 for every series whose observed context is entirely non-negative.

Categorical covariates are target-encoded against the series’ forward-filled context (see timestral.covariate_encoding) and then handled like numeric covariates.

dsipts.models.timestral.layers module¶

Transformer layers for Timestral inference.

Parameter names match the released weights, so they load with strict=True. All tensors use the packed layout: one row per variate of every series in the batch, (R, N, D) with N patches. Time attention runs per row over patches; variate attention runs per patch over the rows of the same series.

dsipts.models.timestral.masks module¶

Attention masks and time positions for Decoupled Horizon Forecasting (DHF) decoding.

The sequence is [Enc ; Dec]: encoder tokens embed the observed context patches; decoder tokens are forecast queries for the horizon patches. All masks are boolean, True meaning “may attend”.

(R, 1, 2N, 2N) time mask over a full [Enc ; Dec] window (the covariate path).

  • Enc to Enc: causal over valid keys; full (non-causal) for bidirectional_rows, the known-future covariates.

  • Enc to Dec: never.

  • Dec to Enc: a decoder token in the block anchored at b reads valid Enc[j], j < b.

dsipts.models.timestral.model module¶

The Timestral network and its single-block forecast primitive.

The model normalizes each row causally per patch, embeds patches from [values, missing] channels, runs a time/variate transformer over [Enc ; Dec] tokens (context patches followed by learned forecast-query tokens), and reads quantiles for every horizon time step from the decoder tokens.

dsipts.models.timestral.model.monotone_quantiles(raw: Tensor, levels: tuple[float, ...], width_factor: float) → Tensor¶

Non-crossing quantiles from raw head outputs along the last axis (monotone_cumsum).

The median channel is free. The others fan out from it as median -/+ cumsum(width_factor * dp * softplus(raw)), dp being the probability gap to the next level inward, so unequal knot spacing is respected.

dsipts.models.timestral.scaler module¶

Normalization for Timestral: causal per-patch mean/std scaling with an asinh squash.

Each patch is normalized with the mean and std of every observed value up to the end of that patch, so the context never sees future statistics. Forecasts come back in the normalized (asinh) space of the last context patch and are inverted with sinh.

dsipts.models.timestral.scaler.advancing_block_frames(context: Tensor, observation_mask: Tensor, sinh_median: Tensor, minimum_scale: float) → tuple[Tensor, Tensor]¶

Per-patch (loc, scale) of a decoded block in the advancing refine frame, each (R, H) float64.

Horizon patch j is normalized with the statistics of the observed context plus the block’s medians of patches 0..j-1, each median denormalized in its own frame before it is folded in. With perfect medians this is causal per-patch normalization of the true series. The statistics are float64 Welford states, accumulated exactly as in training.

Parameters:

  • context – (R, T) block context, T a multiple of the patch size.

  • observation_mask – (R, T).

  • sinh_median – (R, H, patch_size) the block’s median in the last context patch’s frame with the asinh undone, (median - loc) / scale.

  • minimum_scale – Scale floor.

Bases: object

Block-autoregressive quantile forecaster around a TimestralModel.

Parameters:

  • model – The network.

  • max_context – Context cap in time steps (most recent kept); defaults to the trained context length.

  • per_shot_horizon_patches – Patches decoded per block, capped at the trained block size.

  • quantile_real_cap_k – Clamp forecasts to [min - k * s, max + k * s] of the observed context, s being the scale of the last context patch. 0 disables.

  • extreme_value_threshold – Fed-back medians at or above this magnitude become 0.

forecast(context: Tensor | ndarray, prediction_length: int, observation_mask: Tensor | ndarray | None = None, past_covariates: Tensor | ndarray | None = None, known_covariates: Tensor | ndarray | None = None, categorical_past_covariates: Tensor | ndarray | None = None, categorical_known_covariates: Tensor | ndarray | None = None, symmetric_averaging: bool = True, clip_nonnegative: bool = True) → Forecast¶

Forecast prediction_length steps after context.

Parameters:

  • context – (B, V, T), (B, T) (one variate) or (T,) (one series). NaN marks a missing value. The variates of a series are forecast jointly.

  • prediction_length – Horizon in time steps.

  • observation_mask – Optional boolean mask shaped like context; False marks additional missing values.

  • past_covariates – (B, C_past, T) covariates known over the context only.

  • known_covariates – (B, C_known, T + prediction_length) covariates known over the context and the horizon.

  • categorical_past_covariates – (B, C, T) category codes (any numbers; NaN marks a missing value) known over the context only.

  • categorical_known_covariates – (B, C, T + prediction_length) category codes known over the context and the horizon. Categorical covariates are target-encoded per series against the forward-filled target context. A series with several target variates has no single target to encode against, so its codes are used as is.

  • symmetric_averaging – Average with the reflected forecast of -context, with every covariate row negated too.

  • clip_nonnegative – Clamp at 0 the series whose observed context is non-negative.

Returns:

A Forecast with quantiles (B, V, prediction_length, Q).
